Caveat, and it is a large one: the regex matches any dotted lowercase token in quotes, so this table mixes real PxC addresses (`px.badges.px`, `scratch.*`, `input.*`) with strings that were never addresses -- file names (`core.py`, `adapters.js`), attribute paths (`sys.path`, `time.time`), package names and dotted keys.
